# Security policy

Sonara processes user-selected documents and runs local native components. Please report suspected vulnerabilities responsibly.

## Reporting

The repository's private vulnerability reporting setting has not been verified, and no maintainer security email is published. If GitHub displays **Report a vulnerability** for this repository, use that private channel. Otherwise, contact a maintainer privately through a channel already published by the repository owner before sharing exploit details. Do not place sensitive or exploitable details in a public issue.

Include the affected commit or version, operating system, component, impact, reproduction steps, and any safe proof of concept. Remove personal data, document contents, and credentials.

## Supported versions

There are no tagged releases or published support windows identified in this checkout. Until a release policy is adopted, reports should identify the exact commit tested.

## Maintainer action

Enable and verify GitHub private vulnerability reporting or publish a monitored private reporting channel before advertising a formal security response process. No response-time commitment is currently defined.
