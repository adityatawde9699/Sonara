# Support

- **Something is broken:** open a GitHub issue with the Sonara version or commit, operating system, steps to reproduce, expected and actual behavior, and relevant sanitized logs.
- **How do I use or configure Sonara?** Check [the documentation index](docs/README.md), especially [configuration](docs/CONFIGURATION.md) and [troubleshooting](docs/TROUBLESHOOTING.md), then use GitHub Issues for an unresolved usage question.
- **Suggest an improvement:** open a GitHub issue and describe the user problem and expected outcome.
- **Security concern:** follow [SECURITY.md](SECURITY.md); do not include sensitive details in a public issue.

Do not attach private documents, API keys, voice models, or logs containing document text. There is no published response-time commitment or separate support service.
